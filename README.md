# gumroad-product-images

Public image host for [draakaap.gumroad.com](https://draakaap.gumroad.com) product listings — covers, carousels, and app screenshots referenced from the rich-text Description on Gumroad via `raw.githubusercontent.com` URLs.

## Layout

```
second-brain/         — A Second Brain for Claude Code
claude-field-suggest/ — Claude Field Suggest Kit
skill-of-the-week/    — Pre-commit Self-Review (free / PWYW)
```

## URL pattern

```
https://raw.githubusercontent.com/draakaap/gumroad-product-images/main/<product>/<file>.png
```
